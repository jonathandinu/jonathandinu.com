# jonathandinu.com

Comments/discussion for Jonathan's blog -> https://github.com/jonathandinu/jonathandinu.com/discussions

## Code of Conduct

To keep things sane here (i.e. organized), if you would like to write (or read) a comment on a post from [jonathandinu.com](https://jonathandinu.com/writing/), please first check if the [Blog Post Comments category](https://github.com/jonathandinu/jonathandinu.com/discussions/categories/blog-post-comments) already has a discussion started for the psot you are interested in. If for some reason there is not (I try to always create one before publishing), feel free to make one with the title of the post, etc.

For anything that is not a comment or question on the content of a specific blog post, feel free to create a discussion in the general category (or just say hello 👋)

Thank you for reading 🙏
